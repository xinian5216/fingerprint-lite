# Fingerprint Lite v0.1.0-alpha.2

Windows x64 预发布版，汇总 PR #7、#9、#10 的功能与修复。

## 更新内容

- 管理界面和首次启动向导支持简体中文与英文切换。
- 首次下载浏览器时显示已下载大小、百分比、校验和解压等阶段。
- 浏览器恢复搜索功能：默认 Startpage，另可选 DuckDuckGo、Brave Search、Google、Bing。用户更换的默认引擎会保留，搜索建议默认关闭。
- 移除红色鼠标高亮，修复 Windows 最小化、最大化、还原、关闭按钮乱码。
- 修复中文安装路径下 GeoIP 数据库明明存在却报“文件不存在”、导致浏览器无法启动的问题。
- 地理位置检测区分数据库缺失、损坏、读取失败和未收录地址，并显示对应中英文提示。
- 手动检测已保存的代理时，可根据出口国家设置默认语言；已有手动语言设置会保留。

## 下载与升级

Windows 用户下载 `FingerprintLite-0.1.0-alpha.2-windows-x64.zip`，解压后启动 `FingerprintLite.exe`。

升级前退出管理程序及其浏览器，完整备份并保留 `Data`、`Browser`、`Temp`、`paths.env` 和 `Data/config.env` 中的加密密钥，替换程序文件。无需删除、重新创建已有配置，或为中文路径问题重新下载正常的数据库。

本次应用升级继续使用固定的 Camoufox `152.0.4-beta.30` 内核。界面修复在 `Browser/ui-runtime/` 下准备独立副本，首次准备需要额外容纳一份解压后的内核。

## 验证范围与限制

- 已验证中文路径数据库读取、真实浏览器时区、搜索引擎、默认选择保存及中英文提示；打包程序能够在独立中文目录启动、关闭浏览器。
- Windows 便携版不包含 Python、Node 安装要求；原生管理窗口仍需要 WebView2。
- 尚未完成首次启动向导到管理窗口的完整交互稳定性复测，也未测试缺少 WebView2 的环境。
- 程序未签名，Windows 可能显示 SmartScreen 提示。
- SOCKS5 代理认证仍不支持；需要认证时请使用 HTTP/HTTPS 代理。
- Canvas 默认不固定。此 Alpha 版本不承诺完全匿名或不可检测。

校验值和构建来源见 Release 附件 `SHA256SUMS.txt`、`RELEASE-MANIFEST.txt`。
