# Fingerprint Lite v0.1.0-alpha.1 — draft release notes (pre-release)

> **Alpha pre-release for evaluation.** This is not a stable release.

## What is included

- Windows 10/11 x64 portable application (`FingerprintLite-0.1.0-alpha.1-windows-x64.zip`):
  local multi-profile browser environments with one pinned fingerprint per profile.
- HTTP/HTTPS proxies with authentication; SOCKS5 without authentication.
- Custom Data, Browser, and Temp paths; online or offline installation of the
  pinned Camoufox `152.0.4-beta.30` build.
- Profile archive backup and restore, including profile browser data.

## Explicit limitations

- **Windows 10 x64 was the tested platform.** Windows 11 is a stated target but
  has not been independently verified.
- A missing-WebView2-runtime environment has not been tested; WebView2 is
  required for the native Windows window.
- The Windows executable is **unsigned**; SmartScreen may warn before launch.
- Canvas is **not** pinned by default and may vary between launches.
- SOCKS5 proxy credentials are **not** supported; use an authenticated
  HTTP/HTTPS proxy when proxy authentication is required.
- Fingerprint Lite does **not** promise undetectability, untraceability, or
  complete anonymity. Use it lawfully and follow each service's terms.
